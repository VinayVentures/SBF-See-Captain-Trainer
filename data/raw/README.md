# Raw ELWIS source documents

These files are the **official, unmodified** source material for the SBF-See catalogue used by this app.

- `elwis-see-2023.pdf` — *Fragen- und Antwortenkatalog für den amtlichen Sportbootführerschein mit dem Geltungsbereich Seeschifffahrtsstraßen*, Stand 01. August 2023. Downloaded from https://www.elwis.de/DE/Sportschifffahrt/Sportbootfuehrerscheine/Fragenkatalog-See/Fragenkatalog-See-August-2023.pdf
- `fragenverteilung.pdf` — *Verteilung der Fragen auf die einzelnen Fragebogen*. Downloaded from https://www.elwis.de/DE/Sportschifffahrt/Sportbootfuehrerscheine/Fragenverteilung-See.pdf
- `aenderungen.pdf` — *Änderungen des Fragen- und Antwortenkataloges*. Downloaded from https://www.elwis.de/DE/Sportschifffahrt/Sportbootfuehrerscheine/Aenderung-Fragen-Katalog-See.pdf

**© Wasserstraßen- und Schifffahrtsverwaltung des Bundes.** These files are the official published question catalogue. This project uses them as the authoritative source for exam content; the app does not paraphrase or fabricate.

Do not edit these files. To refresh, download the latest published version and update this README with the new "Stand" date.

Parsed output lives in `../catalogue.official.json`, produced by `tools/import-elwis.py`.
