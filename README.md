# SBF See Captain Trainer — Crew Edition

Unofficial bilingual study PWA for the German Sportbootführerschein See.

## v1.3.0 foundation
Bilingual learning UI, notes, explanations, XP/ranks, Bilge revision, mock-exam engine, Navigation Academy structured inputs, progress export/import, and offline/PWA support.

## Official exam rules
Models the current ELWIS structure: 7 Basis questions, 23 See-specific questions, 9 written navigation answers, 60 minutes. Minimums: 5/7 Basis, 18/23 See, 7/9 Navigation.

## Content status
The app never claims incomplete content is complete. The current built-in dataset is a validated starter set. ELWIS publishes 1–72 Basis, 73–285 See and 286–300 navigation. Full catalogue ingestion, official image assets, English translations and educational explanations must be validated before marking the content release exam-complete.

## Leaderboard
The UI is leaderboard-ready. A real multi-user leaderboard requires a backend (planned: Supabase) and project credentials. No secret keys belong in this public repository.

## Disclaimer
Unofficial study aid. Verify current examination information with ELWIS / the responsible examination body.
